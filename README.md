🏎️ AI Smart Racing Game

This is a 2D Top-down Racing Game built using Python and Pygame. The game features multiple difficulty levels, a life system, and a Nitro boost power-up.
🤖 AI Collaboration

This project was developed as a collaborative effort between Human Creativity and AI Assistance. While the core concepts and logic were guided by AI, the fine-tuning of image assets, gameplay mechanics, and difficulty balancing were manually handled to create a unique gaming experience.
✨ Key Features

    5 Challenging Levels: Speed increases as you score.

    Life System: Start with 3 lives and collect heart bonuses to survive.

    Nitro Boost: Pick up Nitro to temporarily speed up and slow down enemies.

    Smart AI Enemies: Enemies track the player's movement!

    Settings Menu: Choose between Easy, Medium, and Hard modes.

To run this game, make sure you have Python installed and run pip install pygame
